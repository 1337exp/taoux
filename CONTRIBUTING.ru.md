# Участие в TaoUX

[English](CONTRIBUTING.md) · **Русский**

TaoUX это набор независимых модулей взаимодействия для Vue-приложений. Здесь коротко, как устроен проект.

## Настройка

```bash
git clone https://github.com/1337exp/taoux.git
cd taoux
npm install
```

| Команда | Что делает |
| --- | --- |
| `npm run typecheck` | `vue-tsc --noEmit` |
| `npm test` | Vitest |
| `npm run build` | `dist/` (Vite для JS и CSS, `vue-tsc` для деклараций) |
| `npm run dev` | наблюдение: пересборка JS и деклараций |
| `npm run sandbox` | демо-страницы, <http://localhost:5300>, берут `src/` напрямую |
| `npm run sandbox:build` | статическая копия песочницы с относительными путями (`sandbox/dist`) |
| `npm run smoke` | упаковывает библиотеку, ставит её во временное приложение рядом с TaoUI и собирает |
| `npm run media` | пересоздаёт скриншоты и ролики, см. [docs/media](docs/media/README.md) |

## Структура

```
src/            один модуль на файл (src/<имя>.ts) или папку (src/<имя>/index.ts)
theme/          taoui.css: мост к TaoUI (--tx-* → --tao-*)
tests/          Vitest; логика модуля чистая и по возможности проверяется без DOM
sandbox/        демо-страницы; они становятся публичной песочницей
docs/           руководства; docs/media: скриншоты и ролики
scripts/        инструменты репозитория: съёмка медиа, дымовой тест «чужого проекта»
```

Новый модуль это файл `src/<имя>.ts` (или папка с `index.ts`) и запись в `exports` в `package.json`;
`tests/exports.test.ts` проверяет, что они совпадают.

## Правила кода

- **Ярусы.** Примитивы ничего не знают о Vue и DOM, если это не их работа. Составные модули импортируют только примитивы.
  Ярус 2 (`curvefield`) единственный, кому разрешено импортировать `@1337exp/taoui`. Это охраняет `tests/tiers.test.ts`.
- **Модуль попадает сюда, когда он нужен второму проекту.** Модулей «на вырост» нет.
- **Дизайн приносите свой.** Компоненты открывают CSS-переменные `--tx-*` с разумными тёмными значениями по умолчанию и без
  зависимости от TaoUI. Добавили цветовую переменную: добавьте её и в [theme/taoui.css](theme/taoui.css), иначе упадёт `tests/bridge.test.ts`.
- **Каждый модуль это своя точка входа** и режется tree-shaking'ом отдельно; Vue-модули кладут CSS рядом с JS, а потребитель
  подключает его явно.
- Тексты для пользователя приходят из приложения (labels, `i18n`), а не из модуля.

## Pull request'ы

1. Ветка от `main`.
2. `npm run typecheck && npm test && npm run build && npm run smoke`.
3. Обновите `README.md` / `README.ru.md`, документацию, страницу песочницы и `CHANGELOG.md`.
4. В описании объясните *зачем*.

Отправляя изменения, вы соглашаетесь, что они распространяются по [лицензии MIT](LICENSE).
